# README screenshots

The 1.0.1 screenshots show the actual HTML generated by the bundled Bright Path
Plumbing demo and `assist`. AI replies are deterministic mock responses, labelled
in the review pages and the npm README. They are illustrations of the workflow,
not output attributed to a live provider. No API key is used.

From a repository checkout, reproduce with an existing Playwright and Chromium installation:

```bash
npm run build
node scripts/capture-screenshots.mjs
```

If Playwright is installed outside the checkout, set `PLAYWRIGHT_MODULE` to its
absolute `index.mjs` path. The script creates a temporary demo, captures the
unmodified pages in Chromium, and removes the temporary files. It does not
install dependencies or browsers. The older `url-coverage.png` is retained as a
historical asset; the current README uses the three refreshed screenshots.
